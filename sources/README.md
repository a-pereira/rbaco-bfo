# Sources

RBACO-BFO is built from three papers. They are the publishers' copyright, so this repository does not include them. `SHA256SUMS` holds the hashes of the copies the work was checked against, under the file names below: put a copy here under its name and `sha256sum -c SHA256SUMS` tells you whether it is the same file. `.gitignore` keeps the papers out of commits.

| File | Citation | DOI |
|---|---|---|
| `finin-2008-rowlbac.pdf` | T. Finin, A. Joshi, L. Kagal, J. Niu, R. Sandhu, W. Winsborough and B. Thuraisingham, "ROWLBAC: Representing Role Based Access Control in OWL", *SACMAT '08*, pp.73–82 | [10.1145/1377836.1377849](https://doi.org/10.1145/1377836.1377849) |
| `ferraiolo-2001-nist-rbac.pdf` | D. F. Ferraiolo, R. Sandhu, S. Gavrila, D. R. Kuhn and R. Chandramouli, "Proposed NIST Standard for Role-Based Access Control", *ACM TISSEC* 4(3), 2001, pp.224–274 | [10.1145/501978.501980](https://doi.org/10.1145/501978.501980) |
| `botha-eloff-2001.pdf` | R. A. Botha and J. H. P. Eloff, "Separation of duties for access control enforcement in workflow environments", *IBM Systems Journal* 40(3), 2001, pp.666–682 | [10.1147/sj.403.0666](https://doi.org/10.1147/sj.403.0666) |

Page numbers cited anywhere in this repository (`p.674`, `pp.224–274`) are the printed page numbers of these papers, not PDF page indices.

A copy downloaded later can differ in bytes from the one hashed here (a cover page added, the file re-rendered), so a mismatch means only that the file is not the same, not that its text differs.
